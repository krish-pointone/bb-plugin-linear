# Linear for bb

A native Linear workspace inside bb.

- Browse Linear custom views and issues.
- Search and filter issues by assignee.
- Create issues and update workflow status.
- Launch bb agents directly from an issue and keep linked threads visible.
- Uses bb's secure plugin storage for the Linear personal API key.

```sh
npm install --include=dev
npm run typecheck
npm run build
bb plugin install . --yes
```
